# Bitlenda

Bitlenda is an early-stage software project focused on building a scalable,
modular system architecture. This repository currently contains the initial
project structure and development roadmap, which will evolve as the project
advances.

## Current Status

- Project initialization
- Base folder structure
- Early specification and planning

## Roadmap

- Define core modules
- Implement service structure
- Add API endpoints
- Integrate persistence layer
- Add tests and documentation

## ENVIRONMENT VARIABLES

## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Update database

```bash
$ npm run db:update
```

## Installation

```bash
$ npm install
```

## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
